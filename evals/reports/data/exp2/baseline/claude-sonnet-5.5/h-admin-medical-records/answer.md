# 病歷複製與調閱申請流程重新檢視

> 說明：以下數字(如占比、天數)為**待驗證的假設**,第 1 週須用實際資料校正。法規部分以台灣現行規範(醫療法、醫師法、個資法、病人自主權利法及相關函釋)為基礎,實際適用條文請由法務/個資窗口確認。

---

## 一、重新定義問題

**表面問題**:病歷室太慢、人手不足。
**較可能的真問題**:1,500 件/月、5 人 ≈ 每人每月 300 件。慢的原因多半**不在「複製動作」本身**,而在**案件進來時不完整、身分與授權要反覆確認、案件在各單位間停等、且所有申請者一律走同一條最重的路**。

可能的瓶頸(需用資料驗證):

1. **退件與補件迴圈**:申請文件不全(委任書、關係證明、身分證明、法院函文),來回補件使一件案子被處理 2–3 次。
2. **等待時間 ≠ 作業時間**:病歷室實際動手可能只占總天數的 10–20%,其餘是等病歷回室(住院病歷未完成、病歷借出未還)、等醫師完成/簽核、等繳費、等通知。
3. **一律走最高風險流程**:病人本人調閱門診摘要與法院調閱全本,審查強度相同,導致低風險件被高風險件拖慢。
4. **無分流與無優先級**:緊急(轉院、續醫)與一般件排同一隊列。
5. **資訊不透明**:申請人不知進度 → 打電話、現場詢問 → 吃掉作業時間(這是「製造出來的工作量」)。

**第一個要做的事**:用 1 週時間量測,不是討論。

## 二、工作量來源拆解

| 類別 | 例子 | 處置原則 |
|---|---|---|
| **法規要求(不可動)** | 確認申請人身分與權限;依法可提供的對象(本人、法定代理人、經授權者、司法機關、保險人須經病人書面同意等);保存稽核紀錄;不得超出範圍提供;未成年/無行為能力者的特別規定 | 保留,但可「標準化」讓審查更快 |
| **法規有彈性、院內過度解讀** | 所有申請都要主任/副院長簽核;一律要正本證件影本而非驗證後留存紀錄;一律收紙本申請書;範圍一律「全本」 | 風險分級,降低審查層級 |
| **歷史習慣** | 紙本多聯單;現場排隊領取;只收上班時間申請;固定每週某天集中處理;手寫登記簿;格式各異的保險公司表單 | 取消或改寫 |
| **互不信任造成** | 臨床科怕被追究 → 要求再簽核;病歷室怕外洩責任 → 多一層檢查;資訊室怕權限 → 不開報表;會計怕漏收費 → 先收費才處理;保險公司/律師被視為「可疑」→ 全部加嚴 | 把「信任」換成**明確規則+留痕**,用事後稽核取代事前重複審查 |
| **製造出來的重工** | 進度查詢電話、補件往返、重複登錄資料、列印後再掃描 | 預防性消除 |

**驗證方法**:隨機抽 100 件已結案案件,逐件畫出每個步驟、時間戳、誰在等誰,並標記該步驟的依據(法條/院內規定/不知道為何)。「不知道為何存在」的步驟是首批候選對象。

## 三、三個層次的改善方案

### 方案 A:入口修正(層次:表單與前置)——「一次收齊,第一次就對」
**內容**
- 依申請人類型(本人/家屬/保險/法院/他院)做**一頁式檢核表**,明列所需文件與可申請範圍,放在櫃台、官網、LINE/電話語音說明。
- 受理時當場以**檢核表勾核**,文件不齊不開案(或開「待補件」並一次告知所有缺項,不分次通知)。
- 統一申請書欄位,限定調閱「範圍」(日期、科別、文件類型)並預設為「最小必要範圍」。
- 資訊室小調整:申請書加必填欄位、補件狀態欄、自動產生案件編號。

| 項目 | 說明 |
|---|---|
| 受益 | 申請人(少跑一趟)、病歷室(減少補件重工)、個資窗口(範圍縮小,洩漏風險降) |
| 受損 | 習慣「先收件再說」的櫃台;偏好全本調閱的保險公司/律師(需說明範圍) |
| 需同意 | 病歷管理委員會或個資窗口(檢核表內容)、法務(範圍條款)、資訊室(表單) |
| 最小試辦 | 只針對「保險公司」與「家屬代領」兩類(通常補件率最高),2–3 週 |
| 成敗指標 | 補件率(基準→下降 ≥30%)、一次受理即完整比例、平均處理往返次數;**護欄**:無範圍超出事件 |

### 方案 B:流程分流(層次:流程設計)——「依風險分三條線」
**內容**
- **綠線(低風險、標準化)**:病人本人、診斷證明/摘要/檢驗報告等固定文件。核對身分即可,病歷室**授權審核**,不經科室簽核,目標 3 個工作天。
- **黃線(中風險)**:家屬/代理人/保險公司/他院轉診。需授權文件齊全,病歷室審核+抽樣複核,目標 5–7 個工作天。
- **紅線(高風險/特殊)**:法院/檢察署/警調、醫療糾紛、精神科/性傳染病/未成年/家暴等敏感病歷。由指定人員處理,雙人覆核、法務知悉。時限依公文為準。
- **緊急插隊**:轉院、續醫需求,當日或隔日。
- **固定批次取代即時中斷**:每日兩個固定時段處理列印/核對,其餘時間處理受理與溝通,避免被電話與臨櫃打斷。
- 單線責任制:每條線有一位「當日負責人」,5 人輪值而非每人樣樣做。

| 項目 | 說明 |
|---|---|
| 受益 | 大多數本人申請者(最快)、病歷室(降低切換成本)、緊急病人 |
| 受損 | 部分臨床科主任(失去對某些低風險件的簽核權,感覺失控);習慣統一處理的同仁(角色改變);高風險件申請者(時間不變甚至更嚴) |
| 需同意 | 院長/醫務主管(授權降級)、病歷管理委員會、個資長與法務(風險分級依據)、各科部主任(知悉) |
| 最小試辦 | 只先上**綠線**(本人申請+固定三類文件),其餘維持原流程;並行追蹤 4 週 |
| 成敗指標 | 綠線中位處理天數(目標 ≤3 天)、積案數、一個月內「超過 7 天」的比率;**護欄**:稽核抽查符合率 100%、零誤發 |

### 方案 C:信任與留痕重設計(層次:治理/結構)——「事前層層簽核 → 事前標準+事後稽核」
**內容**
- 與臨床科、法務、資訊室、個資窗口共同簽一份**「調閱分級授權表」**:誰可在何條件下免簽核直接發出,誰需覆核。把各單位的疑慮寫成明確規則,而不是靠重複簽名。
- **留痕標準化**:每件至少記錄 申請人身分核驗方式、依據文件、範圍、發出人、發出日期/方式、收件確認。用同一張表單/報表欄位統一,資訊室做報表(月報、異常清單)。
- **事後稽核取代事前重複審查**:個資窗口每月隨機抽 5–10% 案件稽核;稽核發現公開回饋給各單位。
- **對外出口安全化**:優先採**面領+驗證、掛號/加密光碟或加密檔案,密碼另行通知**;禁止一般 email 夾帶或個人通訊軟體傳送;發出紀錄留存。
- 與常見申請機構(幾家保險公司、律師團體、鄰近醫院)建立**固定窗口與標準範本**,降低逐件疑慮。
- 臨床科責任界定:病歷完整性(未完成病歷)的催辦機制由醫務/品質部門負責,不由病歷室被動等待。

| 項目 | 說明 |
|---|---|
| 受益 | 病歷室(責任明確,不用個人承擔風險)、院方(稽核更完整)、申請人(更快) |
| 受損 | 習慣用簽核「轉移責任」的主管;部分科室失去否決權;個資窗口多了稽核工作量 |
| 需同意 | 院長(最終授權)、法務與個資長、醫務/品質部門、各科代表、資訊室 |
| 最小試辦 | 選 1–2 個合作意願高的科別 + 一種申請者(如保險公司)先走「授權表+事後稽核」,4 週 |
| 成敗指標 | 簽核層級數、稽核缺失率(目標不增)、跨單位等待天數;**護欄**:任何外洩/誤發事件 = 暫停 |

**建議順序**:A → B(綠線)→ C。A 風險最低、見效最快,為 B、C 取得數據與信任。

## 四、60 天試辦計畫

### 第 0–1 週:量測與對齊(Day 1–7)
- 院長/醫務主管確認試辦授權、風險底線(**零外洩、稽核留痕不減**)。
- 病歷室匯出近 3 個月申請資料(或抽 100 件人工回溯):申請人類型、受理日、完成日、補件次數、卡關位置。
- 繪製現況流程圖並標註每步驟依據(法規/習慣/互信)。
- 對法務確認各類申請人的法定要件清單。
- 產出**基準線(baseline)**:中位處理天數、P90、補件率、積案數、進度詢問電話量、投訴件數。

### 第 2–3 週:設計與準備(Day 8–21)
- 完成檢核表(4 類申請者)、風險分級表(綠/黃/紅)、授權表草案。
- 資訊室小調整:表單必填欄位、補件狀態、週報表(件數、天數、補件、積案)。
- 召開 30 分鐘溝通會:臨床科、法務、個資窗口、資訊室、會計,取得同意。
- 病歷室內部 SOP 1 頁、輪值分工(綠/黃/紅責任人)。

### 第 4–7 週:試辦(Day 22–49)
- **第 4 週**:上線方案 A(保險公司、家屬代領),同時加入固定批次時段。
- **第 5 週**:上線綠線(本人申請,3 類標準文件)。
- **第 6–7 週**:試辦「授權表+事後稽核」於 1–2 科。
- 每週 15 分鐘站會看週報表;每週 1 次小幅調整規則。
- 個資窗口第 6 週做首次抽查(至少 10%)。

### 第 8–9 週:評估與決策(Day 50–60)
- 對比基準線與試辦數據,附上稽核結果與同仁/申請人回饋(5 題簡短問卷)。
- 院長簡報一頁:成果、風險、擴大建議。
- 決策:**擴大 / 調整 / 停止**。

### 里程碑摘要
| 日期 | 里程碑 |
|---|---|
| Day 7 | 基準線完成 |
| Day 21 | 檢核表、分級表、同意取得 |
| Day 28 | 方案 A 上線 |
| Day 35 | 綠線上線 |
| Day 45 | 首次稽核報告 |
| Day 60 | 成果報告與擴大決策 |

### 整體成功指標(Day 60 目標,供參考,依基準線調整)
| 指標 | 目標 |
|---|---|
| 綠線中位處理天數 | ≤3 個工作天 |
| 整體補件率 | 下降 ≥30% |
| 積案(超過 7 天未結) | 下降 ≥40% |
| 進度詢問電話 | 下降 ≥20% |
| 稽核抽查符合率 | 100%(不得低於現況) |
| 外洩/誤發事件 | 0 |
| 病歷室同仁加班時數 | 不增加 |

### 主要風險與對策
- **臨床科抗拒**:先以數據說明,綠線僅限標準文件;保留升級權。
- **試辦期間出錯**:任何誤發即暫停該線並檢討。
- **數據不完整**:先用人工抽樣,不等系統。
- **同仁負荷**:試辦期不加新工作,只替換舊步驟;停止無依據的步驟並登記。
- **法規解讀不確定**:法務書面確認後才上線,不確定者留在黃/紅線。

## 五、你這週就能做的三件事

2. 請法務列出每類申請人「法定必備文件」一頁清單。
3. 約院長、法務、個資窗口 30 分鐘,確認「零外洩+留痕不減」為底線,並取得綠線授權原則。
