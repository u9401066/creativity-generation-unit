### 卡 2：三車道分流（流程設計層）
- **推導路徑**：典型答案 → a2 → 重切分析單位 → 框架 f-6da3fd9a
- **disclosure**：分析單位由「每一件申請」改為「申請類型×風險的案件群（車道）」
- **做法**：
  - A 例行道：病人本人或已授權家屬，申請診斷證明或近期摘要。
  - B 制式機構道：保險公司、他院，使用標準授權書和固定範圍，批次處理。
  - C 重審道：法院、律師、敏感類別、未成年、身故者。
  - A、B 道用檢核清單取代逐件二次人工覆核，改為**抽樣覆核加全量事後稽核報表**。留痕不減反增。
- **受益**：病人和保險公司（A、B 道變快）、病歷室（重審力氣集中在 C 道）。
- **受損**：個資室（覆核由全量變抽樣）；C 道的申請方不會變快。
- **需誰同意**：個資、法務、稽核（最關鍵）、病歷室主管、資訊室（加一個「車道」欄位和報表）。
- **最小試辦**：只試 A 道，且先用影子模式。同仁照舊全量覆核，同時記錄「若用清單會不會漏判」。若漏判率低，再換成抽樣覆核。
- **成敗指標**：
  - A 道中位交付時間下降（目標值待基線，建議先設 −30%）。
  - 抽樣覆核錯誤率不高於現行全量覆核，數值待與稽核共訂。
  - 稽核留痕完整率 100%。
- **主要風險**：
  - 若覆核其實是法規要求，這張卡的核心會被推翻，必須先請法務確認。
  - 車道誤判。
- **新穎度（詞面）**：與典型答案最大相似度 0.104（n=8），三張中最高；最近鄰是「單一窗口依申請人類型分流」，兩者有重疊，差別在我把覆核強度也依風險分級。
- **符合限制**：人力 ✔　不採購系統 ✔　留痕 ✔（前提是法務認可）　60 天 ✔（只試 A 道）
