- **重新定義問題：**不是「老師不夠小心」，而是不同計畫規則、分散的規則解讀、紙本交接與退件後重跑流程，讓必要合規工作和可避免返工混在一起。
- **框架改寫：**把流程拆成「規定來源」「案件交接／補件循環」「必要合規時間與返工時間」三個可檢視單位。
- **產出：**整理出 3 種責任分配不同的改造方案、60 天試辦及 5 項指標；尚未取得校內規章與各計畫契約，不能替個別要求作最終法律分類。

### 先分清工作量來源

目前資料不足以斷言某一項要求一定是法規或校內加碼；例如「採購比價」會受採購類型、金額門檻、經費來源及校內程序影響。應逐項記錄要求的**原文依據、適用計畫／支出、版本、解釋權責單位**；找不到依據時先標「待確認」，不要直接取消。

| 退件／流程項目 | 優先查核的來源 | 可能的校內或單位加碼 |
|---|---|---|
| 單據抬頭、日期 | 發票／憑證規範、補助機關及會計要求；確認究竟是必填欄位錯誤，還是內部格式偏好 | 額外封面、重複抄錄、非必要格式要求 |
| 採購未比價 | 依採購類型與門檻查適用法令、補助條件及校內採購程序；不能假設所有採購都適用同一門檻 | 高於適用依據的報價份數、重複比價或重複初審 |
| 經費項目不符核定計畫 | 核定計畫／預算及補助機關的流用或變更規定；先確認是否可事前申請變更 | 校內額外簽核、但未清楚說明適用範圍的要求 |
| 支出超出執行期間 | 該計畫核定期間、補助契約及可否展延／核銷的規定 | 校內較早的送件截止日，或結案前重複提醒 |
| 多層紙本交接與重複檢查 | 查校規、核決權限表、補助條件是否要求特定簽核、憑證或留痕 | 重複核對同一欄位、重複輸入、非必要紙本副本或單位習慣 |

**校內規章即使是校內加碼，在正式確認可簡化或有權責單位同意前仍須遵守。**最可能的返工來源，是缺乏規則來源索引、不同案件被用同一套檢查方式、錯誤到後段才被發現，以及退件未說清楚補什麼。120 位教師同時有 1–3 件計畫，代表約 120–360 件在辦計畫；相較之下系辦只有 3 位助理，且其中 1 位兼管核銷，規則查找與協調本身也可能是瓶頸。

### 三個改造方案

**方案一｜「計畫案件管家」：把文件追蹤和規則查找從教師移交給明確承辦人**  
每案指定一位現有行政承辦人作窗口；研究助理可依清單整理憑證與附件。教師／主持人保留研究內容、支出必要性、預算判斷及法定或校規要求的簽認；案件管家負責表單完整性、期限、附件索引及送件追蹤；會計室與採購權責單位仍作正式判斷與核決。**權責影響：**重分配準備和追件工作，不轉移核准權。**可能卡點：**三名助理是否有可調度工時、職務分工及利益衝突／分工牽制；不得由承辦人代替主持人作實質認證或簽核。

**方案二｜「規定護照」：每項要求標明來源、適用案件與負責解釋單位**  
由院辦彙整，會計室、採購權責單位及各補助計畫承辦確認，將要求分為法令、補助機關／契約、核定計畫、校內正式規定、單位作業慣例；清單附上依據與版本。教師提供研究及支出實質資訊，不必自行猜哪套規則適用；承辦人按計畫類型套用清單。**權責影響：**把規則維護責任放到有權解釋的單位，而不是各教師各自查找。**可能卡點：**規則互相衝突或校內要求無明確來源時，要由原制定／主管單位確認；試辦可盤點、澄清及統一現行作法，但不能自行宣布規定失效。

**方案三｜「一次說清楚」補正單；有核准依據時才平行預檢**  
退件單位須指出案件、錯誤欄位、適用依據、可接受的補正資料、補正責任人及重送期限；系辦彙整後一次通知教師或研究助理補件，並在 Excel 記錄原因碼及往返次數。若會計室確認不違反現行程序，可加上院辦與會計室的**非核決性**平行預檢；正式簽核仍照原順序與權責辦理。**權責影響：**退件單位負責給出可執行的補正理由，系辦整併通知，教師只補需要其確認的實質事項。**可能卡點：**若規定要求逐關正式審查，就不能以預檢取代或提前核決；未取得會計室及相關單位同意前，只做送件前檢核，不改變正式流轉。

### 60 天試辦：不改規章、不買新系統

試辦建議採**方案一＋方案二＋補正單**；平行預檢只有在權責單位確認屬非核決作業後才加入。用現有紙本與 Excel，先選 10–15 位自願教師、兩種不同補助來源，涵蓋近期計畫申請及常見核銷；以往案件作基準，目標至少比較 30 件核銷與 6 件申請，若案件量不足則只判斷可行性，不宣稱成效已證實。

| 天數 | 工作 |
|---|---|
| 1–7 | 院辦指定流程負責人；從過去案件及退件紀錄建立基準，記錄教師與各單位實際工時、往返及等待點。 |
| 8–14 | 會計室、採購權責單位與院辦共同核對適用規則；完成「依據／適用範圍／版本／解釋單位」表及簡短補正單。 |
| 15–45 | 導入案件管家與紙本附件索引；主持人負責研究內容、預算實質決定及必要簽認，承辦人負責完整性與追蹤；正式審核、核決和出納流程不變。 |
| 46–55 | 抽查憑證與簽核留痕，按計畫類型比較試辦與基準資料，檢查工作是否只是從教師移到助理。 |
| 56–60 | 由院辦、系辦、會計室與教師代表檢討；決定延續、調整或停止，並列出需正式修規的項目（本試辦不處理）。 |

**責任底線：**PI／教師負責研究與支出實質判斷及應由本人簽認事項；研究助理可整理文件但不能代替核准；系辦案件承辦負責適用清單、完整性、追蹤和單一窗口；院辦負責流程與規則版本協調；會計／採購權責單位保留正式法遵判斷、核決及出納權責。

### 量化成敗指標

| 指標 | 建議目標 |
|---|---|
| 每案教師實際行政分鐘數（中位數） | 較基準下降至少 30% |
| 每案教師＋行政人員總投入分鐘數 | 較基準下降至少 10%，避免只把工作轉嫁給助理 |
| 首次送件即完整率 | 提高至少 15 個百分點，或退件率相對下降至少 25% |
| 校內處理工作日 | 從首次送件至文件完整／正式核准的中位天數下降至少 20%；分別記錄各單位等待及待教師補正時間 |
| 合規與稽核軌跡 | 試辦要求來源及負責單位可追溯率 100%；跳過必要簽核或重大不合規件數為 0 |

**發想量測與限制：**三案分別取自「規則來源」「交接單位」「返工工作量」的框架改寫；未做文獻比對，也沒有使用教師自提點子作參照。工具的新穎度只是字元 n-gram 詞面相似度：相對典型答案的最大／平均相似度，三案依序為 0.067／0.026、0.138／0.045、0.083／0.020（參照集各 8）；語意嵌入不可用，不能據此判斷實質新穎。成對評審只用了 GPT-6 Luna 一個評審家族，AB/BA 一致率 2/3；補正單方案在這組評審中勝出，但勝率是未校準的模型判斷，不是客觀品質保證。

**尚待確認：**每一補助機關的實際核銷條文、核定預算變更規則、採購門檻、校內核決與紙本規定，以及三名助理可否調整工時；因此目前不能替個別退件項目斷定「法規必要」或「校內加碼」。
