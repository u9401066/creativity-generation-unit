# 術後居家遠距追蹤:服務化檢視與試辦建議

## 1. 尚未被證明的假設(依風險排序)

| # | 假設 | 為何危險 | 最小驗證方式 |
|---|---|---|---|
| A1 | 病人會持續回報 | 第 5–14 天通常掉得最快,老年關節置換者尤甚 | 試辦測 7 天、14 天完成率 |
| A2 | 回報資料能早期發現惡化,而非只產生雜訊 | 警示敏感度與特異度未知,假警報會壓垮護理 | 回溯比對既有再就醫個案 |
| A3 | 早期發現會改變結局 | 發現後仍需有人處置,否則只是「知道得更早」 | 追蹤警示到處置的時間與結果 |
| A4 | 能減少非必要急診/再入院 | 可能反而增加門診,淨效果不明 | 對照組比較 |
| A5 | 付費方(醫院/保險/長照)願意買 | 醫院的利益是減少再入院,保險是賠付,長照是照護銜接,三者不同 | 先訪談 3 方的付費意願與預算來源 |
| A6 | 護理人力吃緊下仍可負擔 | 這是最大矛盾:服務要用人力解決人力問題 | 實測每位病人的護理分鐘數 |
| A7 | 病人自拍傷口照片可判讀 | 光線、角度、膚色、病人能力差異大 | 判讀一致性測試 |
| A8 | 院內系統介接可行 | 資訊室只允許既有系統,時程可能拖垮試辦 | 先確認介接路徑,見下方 |

## 2. 價值指標

**病人結局(主要)**
- 14 天內非計畫性急診、再入院、非預期回診率
- 傷口感染的確診天數(從出現症狀到被處置)
- 疼痛控制:NRS ≥7 持續天數;活動恢復里程碑

**服務表現(過程)**
- 回報完成率(第 3、7、14 天)
- 警示陽性預測值,即警示中真正需介入的比例
- 警示到處置的時間中位數
- 每位病人護理分鐘數(A6 的關鍵)

**經濟(賣給付費方)**
- 避免的再入院/急診成本 減 服務成本
- 病人滿意度、護理人員負荷感受

**反向指標(不能只看好處)**:非必要回診增加、病人焦慮、夜間漏接事件。

## 3. 法規與個資的容易被忽略處

1. **醫療器材界定**:若系統自動分級、判讀傷口影像或給出臨床建議,可能被認定為軟體醫療器材(SaMD),需查衛福部食藥署規範。僅收集資料與人工判讀風險較低。
2. **責任歸屬**:警示發出後誰在多少時間內處理?夜間與假日呢?病人在 App 寫「發燒」卻沒人回,是最大的醫療糾紛來源。需有書面服務水準與病人端的明確免責/急診指引。
3. **個資法與特種個資**:病歷、醫療資料屬特種個資,需明確告知同意;傷口照片可能含臉部、刺青等可識別資訊。保險方取得資料需獨立同意,不能打包。
4. **目的外使用**:醫院資料給保險公司做核保或理賠,是高度敏感的風險點。
5. **委外與資安**:廠商是受託處理者,需契約、稽核、資料存放地點、刪除機制;醫院資安評鑑與資通安全管理法要求需對照。
6. **遠距醫療範圍**:通訊診察治療辦法對適用對象與方式有限制;護理追蹤與醫師診療要分清楚。
7. **病人身分與代理**:高齡者多由家屬代操作,同意與資料權限要處理。
8. **介接限制**:資訊室不允許外部直連,意味著資料可能無法即時回寫病歷。需設計為「系統外獨立介面 + 人工摘要入病歷」,或採院內入口網站,但要先與資訊室確認。
9. **保存與病歷定位**:追蹤紀錄是否屬病歷,保存年限與修改軌跡需確認。

(以上為提醒清單,具體條文請由醫院法務與專業法律顧問確認。)

## 4. 誰會抵制(以及為什麼)

| 角色 | 擔憂 | 對策 |
|---|---|---|
| 外科護理師 | 增加額外工作、假警報、責任無限延伸 | 由專責人員或集中式團隊處理,不增加病房人力;承諾警示量上限 |
| 個管師/出院準備服務 | 與現有電話追蹤重疊、角色被取代 | 以取代電話追蹤的方式設計,不疊加 |
| 外科醫師 | 被半夜通知、責任擴大、擔心拍照傷口的判讀責任 | 分級升級路徑,醫師只處理經護理確認的個案 |
| 資訊室 | 資安與維運負擔 | 使用最小介接,廠商負擔資安審查 |
| 急診科 | 轉診湧入 | 事先溝通分流流程 |
| 病人/家屬 | 數位落差、隱私、被監看的感覺 | 提供電話替代路徑 |
| 院內品質/法務 | 事故責任 | 事先確定通報與紀錄流程 |
| 醫院管理層 | 若無再入院節省數據,無法支撐預算 | 以指標對應其 KPI |

## 5. 三種服務設計

**設計 A:被動型自助追蹤(低介入)**
病人每日填問卷與選擇性上傳照片,系統依規則顯示建議(如「請回診」),護理不主動追蹤,只處理病人主動求助或高風險警示。
責任:病人自主,醫院僅被動回應。

**設計 B:分級型護理主導追蹤(中介入,推薦試辦)**
每日簡短回報(約 1 分鐘),規則引擎分三級:綠(無動作)、黃(24 小時內由專責護理電話)、紅(當日處置,必要時轉醫師或急診)。由集中式、少量專責護理人員(非病房護理)處理,營業時段內響應。
責任:醫院保有臨床判斷,廠商提供平台與營運支援。

**設計 C:全程專人與遠距醫師型(高介入)**
固定時段視訊或電話,專人 24 小時監看,醫師可遠距處置,可含居家護理與長照銜接。
責任:服務方承擔較高臨床責任。

| 面向 | A 被動型 | B 分級護理型 | C 全程專人型 |
|---|---|---|---|
| 臨床價值 | 低,依賴病人自覺,可能延遲發現 | 中高,重點在早發現與分流 | 最高,但邊際價值遞減 |
| 營運成本 | 最低 | 中,可控(約每病人每日分鐘數可測) | 高,人員密集 |
| 對護理人力 | 幾乎不增加 | 專責人員吸收,病房影響小 | 需大量新增人力 |
| 法規風險 | 中,免責聲明不足,「沒人看」反而是風險 | 中,責任界線清楚 | 高,涉及遠距診療與責任擴大 |
| 可賣性 | 價格低但價值難證明 | 醫院與保險較易理解 | 價格高,較適合高風險族群 |
| 抵制程度 | 低 | 中 | 高 |

B 的取捨是:它是唯一同時能檢驗 A2、A3、A6 三個核心假設的設計,而且成本與風險可控。A 無法證明價值,C 在護理人力吃緊的環境不可行。

## 6. 建議試辦:設計 B

**對象**:腹腔鏡手術 + 關節置換各一半,先做約 80–120 人,各自分層。若要比較,採用同期對照或前後對照:
- 同期隨機或依病房/週別輪流分配(較好,但需院方同意)
- 若不行,與歷史同期出院病人比較(較弱,需註明偏差)

**資料流程**:使用院內既有出院衛教或個管系統,或以獨立入口加人工摘要;先與資訊室確認符合規定的路徑再開始,這是第 0 階段。

**時程(約 4 個月)**
- 第 0–4 週:資訊室、法務、同意書、警示規則、處置流程、基線資料(既有再入院率與電話追蹤耗時)
- 第 5–12 週:收案 14 天追蹤
- 第 13–16 週:分析與訪談

**警示規則**:由外科醫師與護理共同制定(如體溫、傷口紅腫滲液、疼痛變化、無法活動),並事先預計警示量上限,每位專責護理每日不超過可處理的案數。

**成功判準(須全部達到,避免只挑好看的)**
1. 7 天回報完成率 ≥70%,14 天 ≥55%
2. 黃/紅警示的陽性預測值 ≥30%,且處置時效達標(黃 24 小時、紅當日)達 90%
3. 每位病人平均護理時間 ≤ 現行電話追蹤時間,或每位專責人員可管理案數達預定目標
4. 非計畫性急診/再入院/回診率不劣於對照,並且在臨床意義上有改善趨勢(小樣本不要求顯著,但看方向與事件案例)
5. 零重大安全事件(警示未處理而致傷害)
6. 護理人員與病人滿意度達預定門檻

**失敗或暫停判準**
- 完成率低於 50%,代表流程或族群不適合
- 警示陽性預測值 <15%,代表規則需大改,否則假警報壓垮人力
- 單一病人護理時間高於現行電話追蹤,代表不可擴張
- 出現警示漏處置致傷害事件,立即暫停檢討
- 資訊室或法務在第 0 階段無法放行,先停,不用硬做

**需要誠實面對的限制**:100 人無法證明再入院率下降,因為此類事件本身發生率低。試辦主要證明可行性、負荷與警示品質,效果證明要留給下一階段的較大樣本。因此與付費方溝通時,試辦成果應表達為「營運可行與安全」,不要過度宣稱經濟效益。
