# 框架審查報告：老年髖部骨折術後譫妄

**限制先講：** 我沒有查文獻，也沒有看你的資料。以下是依領域知識做的推論，要驗證。優先度和閘門判定是我自己的估計，未校準。這份報告不宣稱任何切入點「新穎」。語意嵌入不可用，所以新穎度無法量測。我也沒有做「概念審查」和「準則系譜」。閘門是我自評，沒找反方複審。

## 1. 問題框架與不質疑的前提
- 問題：預測模型與藥物預防已飽和，我們是否問錯問題？
- 不質疑的前提：譫妄對病人有害，值得處理；族群限於髖部骨折。
- 六個直覺答案可以歸成一句話：**以病人風險因子為中心，以「發生與否」為結局。** 這就是框架的異常訊號。

## 3. 通過閘門的三個切入點

### 切入點 A：結局重新定義——短暫譫妄 vs 持續譫妄（a1、a2）
- **重新定義：** 從「誰會得譫妄」改成「哪一種譫妄值得介入」。
- **要驗證的問題：** 校正術前認知與衰弱後，只持續單一班的譫妄，和持續 ≥2 天的譫妄，對出院去向與住院天數的預測力是否不同？
- **現有資料怎麼做：** 用每班 CAM 建出持續時間、起始時間、波動型態。再做校正模型，比較「單班陽性」「持續」「從未陽性」三組。術前認知缺漏用多重插補，並做敏感度分析。
- **會改變臨床做法的結論：**
  - 若單班譫妄與預後無關，現行「任一班陽性」的結局定義就把雜訊當成事件。試驗主要終點應改為持續性譫妄，護理資源也該集中在持續者。
  - 若校正後所有譫妄的預後效應都消失，譫妄多半是標記。這時價值在於觸發出院規劃與認知追蹤，而不是把預防當成改善預後的手段。
- **證據限制：** 觀察性資料證明不了因果，只能檢驗「標記」假說是否站得住。

### 切入點 B：暴露重新定義——可改變的流程 × 脆弱度（a3、a4、a6）
- **重新定義：** 從「誰高風險」改成「哪種系統暴露對哪種病人傷害最大」。
- **要驗證的問題：** 等手術時間、夜間手術、術中低血壓、麻醉方式對譫妄的效果，是否隨術前認知狀態而不同？
- **現有資料怎麼做：** 用 target-trial emulation 的思路，以「入院到手術時間」「手術時段」「術中低血壓累積時間」作暴露，檢驗與術前認知的交互作用。
- **會改變臨床做法的結論：**
  - 若只有認知受損者受低血壓或全身麻醉影響，就可以做分層路徑：這群人優先排程、用較嚴的血壓目標。
  - 若沒有交互作用，這條路線就關閉，把資源放回全體一致的做法。
- **主要風險：**
  - 麻醉方式有適應症混淆，因為脊椎麻醉的選擇與病人狀況相關。
  - 900 例約有 200 個譫妄事件（以 20–30% 估計，未實際查），只偵測得到大的交互作用。報告時用效應量加信賴區間，不要只看 p 值。
  - 術前認知有缺漏，缺漏本身可能和病情嚴重度相關。

### 切入點 C：測量重新定義——CAM 本身是被照護條件影響的結局（a5）
- **重新定義：** 先問「我們量到的譫妄是什麼」，再問怎麼預防。
- **要驗證的問題：** 護理師每班 CAM 相對於研究者獨立評估的敏感度多高？漏判是否集中在夜班、低活動型、認知已受損者？
- **現有資料怎麼做：** 先用既有資料看 CAM 陽性率在班別、病房、評估者之間的差異，以及缺漏評估是否有規律。再做小型前瞻：約 60–100 位病人，由研究者在同一天獨立做 3D-CAM，對照護理師的記錄。可同時加入家屬版 FAM-CAM。樣本數只是粗估，需要實際計算。
- **會改變臨床做法的結論：**
  - 若敏感度低或漏判有系統性，病房篩檢流程要改（例如加入家屬評估、調整夜班評估時機）。
  - 若偏誤方向會影響 A 和 B 的結論，這就是 A、B 的前置條件，要先做。
- **預期性質：** 這是修正測量與流程的結論，不直接降低譫妄發生率。

以下是依臨床常識的推測，應該用訪談或問卷驗證。

| 角色 | 看問題的角度 | 與上述切入點的關聯 |

| 病人 | 在意能否回家、是否還認得人，不在意 CAM 是否陽性 | A：結局該是功能與認知，而非譫妄本身 |
| 家屬 | 最早注意到「不像平常的他」，也是照護者與決策者 | C：家屬版評估可能比護理 CAM 更早偵測 |

## 5. 看起來新、但不值得做的方向
這些我是從已有資料與臨床邏輯推測的，沒有查文獻確認。

1. **再做一個預測模型，加機器學習或生物標記。** 九百例的資料量不夠，且 a3 沒解決：預測之後沒有不同的行動，準確度提高也不改變做法。
2. **用 900 例觀察性資料比較新的預防藥物。** 沒有隨機化，混淆無法處理，結論最多是相關。藥物預防本來就是你說已飽和的方向。
3. **比較脊椎與全身麻醉的譫妄發生率（不分層）。** 這是典型題，而且有適應症混淆。只有放進切入點 B 的「依認知分層」框架才有新意。
4. **「譫妄的本質是什麼」這類哲學式提問。** 不可操作，也不會改變任何決策，屬於偽深刻。
5. **用穿戴裝置或睡眠監測補資料。** 你沒有這些資料，要做就是全新的前瞻研究。在 C 的測量問題還沒釐清前，投入不划算。
