## 點子卡 1：問題改成「譫妄被處置前拖了多久」，不問「會不會發生」
- **推導路徑**：典型答案（預測、預防、分析對住院天數的影響）→ 假設 a3 → 算子 `negate` → 框架 f-ee17c0e0。
- **disclosure（逐字）**：「[core] 研究目標是『降低發生率』→ 【反轉】研究目標不是降低發生率，而是『縮短未被辨識／未被處置的譫妄時間、並降低譫妄造成的後續傷害（住院天數、出院去向）』」。
- **隱性假設**：結局是「有／無」；一旦陽性就會被處置；預防比縮短病程更有價值。
- **利害關係人看法**：

| 角色 | 角度 |
|---|---|
| 病人 | 在意的是清醒回來的速度和能否回家，不是統計上的「發生」 |
| 家屬 | 最先察覺異常，但無通報管道 |
| 護理 | 陽性之後常沒有明確的標準處置路徑 |
| 外科 | 把譫妄視為「麻醉或老人的問題」，無人負責 |
| 麻醉 | 視為術中因素，術後即離場 |

- **用現有資料驗證**：把每班 CAM 重排成長表，算首次陽性班數、持續班數與復發。以首次陽性到第一個處置動作的延遲為時變暴露，做 landmark 分析，結局為住院天數與出院去向，並調整術前功能與認知。
- **小型前瞻**：約 60 例，在病房記錄處置動作的時間戳（停導尿管、調藥、會診、家屬陪伴）。
- **可能改變臨床做法的結論**：若延遲每多一班，住院天數或機構化風險就上升，就能支持「陽性後 X 小時內的標準處置包」，並把責任歸給特定角色。若無關聯，則不必投入處置流程改造。
- **新穎度（詞面，非語意）**：與典型答案最大相似度 0.233，平均 0.054，參照集 n=8。最近鄰是「分析譫妄對住院天數與出院去向的影響」，與該方向有明顯主題重疊。
- **風險**：1) 處置延遲與嚴重度混淆（嚴重者反而處置更早）；2) 現有病歷可能沒有處置時間戳。
- **最小驗證**：1 週內由研究助理抽 50 份病歷，確認「首次陽性」和「處置」能否取到時間。取不到的比例超過一半，就改走前瞻。

## 點子卡 2：把 CAM 當成「有偏誤、缺漏有資訊」的測量，不當真值
- **推導路徑**：典型答案 → 假設 a2 → 算子 `negate` → 框架 f-7c0e7425。
- **disclosure（逐字）**：「【反轉】CAM 每班記錄不等於真實譫妄，缺漏與評估頻率本身帶資訊：缺漏或『無法評估』集中在夜班、低活動型、較虛弱或較嗜睡的病人，因此 CAM 陰性＝『未被偵測』，且缺漏模式本身是臨床訊號」。
- **隱性假設**：缺漏是隨機的；CAM 陰性就是沒有譫妄；低活動型和高活動型可以放在一起算。
- **利害關係人看法**：

| 角色 | 角度 |
|---|---|
| 護理 | 夜班人力有限，「無法評估」可能代表嗜睡，而非資料缺失 |
| 麻醉／外科 | 以「發生率」比較麻醉方式，其實也在比較被偵測到的機率 |
| 病人／家屬 | 安靜的低活動型最常被當成「很乖」 |

- **用現有資料驗證**：統計 CAM 缺漏與「無法評估」在班別、時段、病人特徵上的分布；檢驗缺漏班數能否預測出院去向。用 pattern-mixture 或 tipping-point 敏感度分析，重算麻醉方式、術中血壓與譫妄的既有結論。再以護理紀錄關鍵字（嗜睡、躁動、約束、拒食）建構病歷法譫妄，與 CAM 對照。
- **小型前瞻**：約 100 例，由研究者以 4AT 或 3D-CAM 獨立重評，估計護理 CAM 的漏診率（分夜班與日班）。
- **可能改變臨床做法的結論**：若夜班或低活動型漏診嚴重，就要改評估時段與工具，並重新解讀既有的預防與預測研究。若缺漏本身能預測預後，它可以直接當作警示訊號。
- **新穎度（詞面）**：候選 i-e7a73d0e 對典型答案最大相似度 0.134，i-a9c93058 為 0.106，參照集 n=8。
- **風險**：1) 獨立評估者的 4AT 並非金標準；2) 現有病歷關鍵字的品質不明。
- **最小驗證**：先算缺漏分布，不需新資料。若缺漏在班別與病人特徵上沒有任何結構，這個點子就被推翻。

## 點子卡 3：把「病房×班別」當暴露，不當背景
- **推導路徑**：典型答案 → 單位 → 算子 `recut_unit` → 框架 f-98ab183a。
- **disclosure（逐字）**：「病人 → 病房×班別（病人在病房的某一班；先以『病人×班』面板資料，再聚合到病房／團隊系統層級）」。
- **隱性假設**：風險來自病人與術前術中因子，病房流程只是背景。這是未經檢驗的假設 a4。
- **利害關係人看法**：護理與病人在夜間、週末最直接承受流程影響；外科與麻醉只看到「某個病人」，看不到班別層級的模式。
- **用現有資料驗證**：病人×班別長表，用混合效應模型看夜班、週末或假日、入院日對 CAM 陽性率與缺漏率的影響。
- **小型前瞻**：case-crossover，約 60–100 例，每位譫妄病人比較陽性前一班與自身對照班的可改變暴露（夜間生命徵象與抽血次數、導尿管、約束、轉床、給藥時間、家屬在場）。
- **可能改變臨床做法的結論**：若夜間干擾或某類暴露與下一班陽性相關，就能提出「夜間照護整併」之類可直接試行的流程改變，不需新藥或新模型。
- **新穎度（詞面）**：i-357651e9 對典型答案最大相似度 0.095，i-dc6a8f9a 為 0.066，參照集 n=8，是這批候選中最低。
- **風險**：1) 班別效應可能被偵測偏誤（卡片 2）混淆，兩者需一起看；2) 現有資料可能沒有護病比，需前瞻補。
- **最小驗證**：2 週內以現有 CAM 時間戳畫出各班別陽性率與缺漏率，沒有班別差異就降級。
